# ระบบติดตามสถานะการเรียกเก็บค่าขนส่ง (Freight Billing Tracker)

เว็บแอปพลิเคชันสำหรับติดตามและตรวจสอบสถานะการเรียกเก็บค่าขนส่งของ 3 บริษัท ได้แก่ **SCGJWD**, **NST** และ **RTT**

---

## 1. จุดเด่นและข้อกำหนดหลักของระบบ

1. **ชื่อบริษัทขนส่ง 3 บริษัท (ไม่มีคำต่อท้าย):**
   - `SCGJWD`
   - `NST`
   - `RTT`

2. **การอัพเดทสถานะ:**
   - **บริษัทขนส่งเป็นผู้อัพเดทสถานะเท่านั้น** (ผู้ว่าจ้างไม่ต้องอัพเดท โดยผู้ว่าจ้างมีหน้าที่ติดตามภาพรวมและตรวจสอบรายงาน)
   - สถานะแบ่งเป็น 3 สถานะ:
     - 🟡 **1. บริษัทขนส่งแจ้งยอด** (Transport แจ้งยอดเข้ามา)
     - 🔴 **2. อยู่ระหว่างแก้ไขข้อมูลเพิ่มเติม** (มีข้อทักท้วงหรือต้องปรับปรุงข้อมูล)
     - 🟢 **3. ผู้ว่าจ้างยืนยันยอดค่าขนส่ง** (ดำเนินการสำเร็จเรียบร้อย)

3. **หน้า Dashboard ภาพรวม 3 เดือนล่าสุด:**
   - แสดงสถานะรอบการเรียกเก็บค่าขนส่งของทั้ง 3 เดือนล่าสุด
   - แสดงชัดเจนตามสถานะทั้ง 3 สถานะ
   - มีกล่องแจ้งเตือนรายการที่ยังค้างอยู่ พร้อมแถบเปอร์เซ็นต์ความคืบหน้าแยกตามแต่ละบริษัท

4. **แบ่งการเรียกเก็บค่าขนส่งออกเป็น 4 ส่วนงานหลัก:**
   - 🏢 **1. งานขนส่งกระจายสาขา (บาท)**
   - 🏬 **2. งานขนส่งร้าน MT (บาท)**
   - 🚚 **3. ค่าบริการงานขนส่ง (บาท)**
   - 📦 **4. งานขนส่งเพิ่มเติมอื่นๆ (บาท)**
   - 💰 **ยอดรวมค่าขนส่ง:** คำนวณให้อัตโนมัติแบบ Real-time จากทั้ง 4 ส่วน
